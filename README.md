# Le Trinh An — personal site

Pixel-art burgundy landing page. React + Vite. Deployed on Vercel.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Connect this GitHub repo to [Vercel](https://vercel.com) (Framework Preset: Vite). Or:

```bash
npx vercel
```
