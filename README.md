# Le Tri Nhan

Personal pixel-art landing page for Lê Trí Nhân. Root hub for Quarto notebooks.

React and Vite. Deployed on GitHub Pages: [letrinhandn.github.io/letrinhan-site](https://letrinhandn.github.io/letrinhan-site/)

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Push to `main`. GitHub Actions builds and publishes to Pages.
