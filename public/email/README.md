# Email signature

Preview + copy page (after deploy):

https://letrinhandn.github.io/letrinhan-site/email/signature.html

## Gmail
1. Open the preview page → **Copy chữ ký VI** (or English).
2. Gmail → Settings → See all settings → **General** → **Signature**.
3. Paste into a new signature → Save changes.

## Outlook / Apple Mail
Paste the copied HTML signature into the signature editor. Prefer “paste as rich text / HTML”.

Icons live in `/public/email/*.png` and are served from the site CDN.
